## 💡 Ключевые направления и компетенции

- **Алгоритмы и структуры данных:** разработка динамических структур (двусвязные списки, деревья, очереди), реализация эффективных сортировок (QuickSort) и алгоритмов поиска.
- **Низкоуровневое программирование:** работа с оперативной памятью без утечек (`Valgrind` / `ASan` clean), указатели и структуры на чистом Си (C99).
- **Системные интерфейсы POSIX:** прямое управление терминалом в неканоническом режиме (`termios`), работа со строками широких символов (`wchar_t`) и кастомные оконные TUI-интерфейсы без сторонних библиотек.
- **Инженерная культура:** валидация входных данных, отказоустойчивость, бинарная сериализация и структурированная документация.
